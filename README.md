# 公众号 HTML 导入

<img src="icons/icon-128.png" width="96" alt="公众号 HTML 导入">

在微信公众号图文编辑页里导入 HTML。扩展会在右上角「文档导入」左侧放一个「导入」按钮，带图标和与该按钮相同的浅灰背景。点击扩展图标也会打开同一个弹窗。

弹窗里可以粘贴 HTML，或上传 `.html` 文件。确认后：

- `<title>` 写入「请在这里输入标题」。没有标题时不改动已有标题
- 正文写在光标所在段落之后；没有光标时追加到文末
- `<style>` 转成行内样式，`:root` 里的 CSS 变量会先换成实际值
- 图片按来源分别处理

| 图片 | 处理 |
| --- | --- |
| 本地路径 | 选择同名图片，或选择文件夹，按文件名和相对路径匹配 |
| 远程图片、`data:` 图片 | 确认导入时下载并上传到微信素材库 |
| `mmbiz.qpic.cn` 等微信 CDN | 保持原地址 |

未匹配或上传失败的图片会从正文里去掉。外链样式表和音视频不会自动上传。

## 安装

1. 打开 Chrome，进入 `chrome://extensions/`
2. 打开「开发者模式」
3. 选择「加载已解压的扩展程序」，指向本目录
4. 打开已登录的公众号图文编辑页并刷新

## 参考

图片分类、`/cgi-bin/filetransfer` 上传、样式内联，以及去掉 `text-indent` 的处理，参考了 [html2article-mpwx](https://github.com/ytygxfmgzx/html2article-mpwx)。

本扩展把入口放进编辑页，而不是浏览器工具栏弹窗。写入正文时直接插入 DOM，避免编辑器把粘贴内容的样式清掉；`<title>` 会填进标题栏，而不是留在正文里。

图片上传依赖公众号编辑页的登录态，必须在已登录的编辑页中使用。
